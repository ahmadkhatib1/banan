# 🎓 النظام التعليمي الإلكتروني - EduLes

نظام تعليمي إلكتروني شامل مبني بتقنيات حديثة لإدارة الدورات والطلاب والمحتوى التعليمي.

## 🏗️ هيكل المشروع

```
edu-les-two/
├── frontend/              # React 18 + Vite
├── backend-express/       # Express.js + SQLite
├── admin-setup.html       # إعداد المسؤول الأول
├── seed-data.html        # إدارة البيانات التجريبية
├── test-crud.html        # اختبار عمليات CRUD
├── system-test.html      # اختبارات النظام
├── comprehensive-test.html # اختبار شامل
└── README.md
```

## 🌟 الميزات الرئيسية

### 🔐 نظام المصادقة والتفويض
- تسجيل دخول آمن للمستخدمين
- أدوار متعددة (مسؤول عام، مدرب، طالب)
- حماية نقاط النهاية بـ JWT
- إعداد حساب المسؤول الأول

### 👥 إدارة المستخدمين
- إنشاء وتعديل وحذف المستخدمين
- أدوار مختلفة للمستخدمين
- ملفات شخصية مفصلة
- إحصائيات المستخدمين

### 📚 إدارة المحتوى التعليمي
- **الفئات**: تصنيف الدورات حسب المجالات
- **الدورات**: إنشاء وإدارة الدورات التعليمية
- **الدروس**: محتوى تفصيلي لكل درس
- **التسجيل**: نظام تسجيل الطلاب في الدورات

### 🧪 نظام الاختبار والتطوير
- بيانات تجريبية تلقائية
- اختبارات CRUD شاملة
- اختبارات التكامل
- واجهات اختبار متعددة

## 💻 التقنيات المستخدمة

### Frontend
- React 18 + Vite
- JavaScript (ES6+)
- CSS3 + Responsive Design
- Fetch API للتواصل مع الخادم

### Backend
- Node.js + Express.js
- SQLite قاعدة البيانات
- JWT Authentication
- bcrypt لتشفير كلمات المرور
- CORS للأمان

## ## 🚀 البدء السريع

### متطلبات النظام
- Node.js (v16 أو أحدث)
- npm أو yarn
- متصفح ويب حديث

### تشغيل Backend
```bash
cd backend-express
npm install
npm run dev
```
الخادم سيعمل على: `http://localhost:5000`

### تشغيل Frontend
```bash
cd frontend
npm install
npm run dev
```
التطبيق سيعمل على: `http://localhost:5173`

### إعداد النظام
1. **إنشاء المسؤول الأول**: افتح `admin-setup.html`
2. **إنشاء البيانات التجريبية**: افتح `seed-data.html`
3. **اختبار النظام**: افتح `comprehensive-test.html`

## 📋 نقاط النهاية API

### المصادقة
- `POST /api/auth/login` - تسجيل الدخول
- `POST /api/auth/register` - تسجيل جديد
- `GET /api/auth/profile` - الملف الشخصي

### المستخدمين
- `GET /api/users` - جلب جميع المستخدمين
- `POST /api/users` - إنشاء مستخدم جديد
- `PUT /api/users/:id` - تحديث مستخدم
- `DELETE /api/users/:id` - حذف مستخدم

### الفئات
- `GET /api/categories` - جلب جميع الفئات
- `POST /api/categories` - إنشاء فئة جديدة
- `PUT /api/categories/:id` - تحديث فئة
- `DELETE /api/categories/:id` - حذف فئة

### الدورات
- `GET /api/courses` - جلب جميع الدورات
- `POST /api/courses` - إنشاء دورة جديدة
- `PUT /api/courses/:id` - تحديث دورة
- `DELETE /api/courses/:id` - حذف دورة

### الدروس
- `GET /api/lessons` - جلب جميع الدروس
- `POST /api/lessons` - إنشاء درس جديد
- `PUT /api/lessons/:id` - تحديث درس
- `DELETE /api/lessons/:id` - حذف درس
